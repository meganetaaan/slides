# 起動手順 / Launch

WeChatなどで受け取ったZIPをPCへ保存し、すべてのファイルを同じフォルダーへ展開してください。展開後の `index.html` をChromeで開けば利用できます。ZIP内のファイルやWeChatのプレビューからは起動しないでください。

Chromeでは直接起動で27枚・6本のGIF・発表者画面の動作を確認しています。ソフトのインストールやビルドは不要です。

別のブラウザで表示や発表者画面に問題がある場合は、展開先でローカルHTTPサーバーを起動してください。Python 3 がある場合の例:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8765/` を開きます。8765を使用中なら別の番号に変えてください。reveal.js・フォント・画像・6本のGIFは同梱済みで、インターネット接続は不要です。

- 矢印キー / Space / スワイプ: ページ切替
- S: 発表者画面（必要ならポップアップを許可）
- F: 全画面
- Esc: 一覧
